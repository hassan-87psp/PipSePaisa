PipSePaisa V219 — Pivot Indicator First Product

What this patch adds
- First published product: PipSePaisa Pivot Indicator — MT5
- Free, but NOT a public/direct download
- User request requires Trading Account ID, Broker and Deposit Proof
- Existing Admin request workflow can review the request and upload a user-specific licensed build
- MQL5-style information hierarchy with original PipSePaisa UI (not an MQL5 visual copy)
- Product gallery using the two supplied screenshots
- Product tabs: Overview, Features, How It Works, Installation, License, Risk
- Dark/light theme support through existing PipSePaisa variables
- Responsive/mobile layout

Install
1) The EA & Indicator marketplace from V215/V215.1 must already exist.
2) Run 89_V219_PIVOT_INDICATOR.sql in Supabase SQL Editor.
3) Upload/merge the frontend files and assets from this patch.
4) Hard refresh once if the old EA & Indicator JS is cached.

No Edge Function deployment is required.
