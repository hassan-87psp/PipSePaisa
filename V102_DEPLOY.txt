PipSePaisa V102 — Responsive Signals UI
20 August 2026

WHAT CHANGED
- Desktop/Laptop Active Signals now use the same compact horizontal table style as History.
- Desktop columns: Date, Pair, Type, Entry, SL, TP1, TP2, TP3, Status, Pips, State.
- History remains compact table-based.
- Mobile Signals now use a Dott-Plus-inspired compact expandable list, recreated in PipSePaisa theme.
- Mobile row: Date, Pair, Status, Profit, Open.
- Tap/Open expands a premium PipSePaisa detail card with Direction, Pair, Entry, SL, TP1-TP3, Status and Pips.
- Mobile bottom Daily / Weekly / Monthly buttons show closed-signal result tables.
- Period summary shows Total Green Pips, Total Red Pips and Net Result.
- Signal VIP locking/access restrictions are preserved.
- Exact PipSePaisa orange accent #FB9201 is used for the new signal UI.
- No Signal database schema changes.
- No Mentor publishing logic changes.
- No Infinity API / Edge Function / payment changes.
