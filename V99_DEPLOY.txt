PipSePaisa V99 — Direct Paid Checkout + Infinity Redirect Fix

WHAT THIS PATCH FIXES
1) Signed-in paid-course users choose the payment method only once.
2) Local Bank Transfer selection goes directly to the Infinity hosted payment page.
3) The old Enrollment Details / second Payment Method screen is skipped for Local Bank Transfer.
4) USDT TRC20 selection goes directly to the USDT payment details + Transaction ID + Receipt form.
5) MANUAL / SECURE HOSTED badges are removed from the secondary payment picker.
6) No password or account question is shown again for a user who is already signed in.
7) V98.1 redirect bug fixed: Query 60 defines prepare_infinity_payment with 3 parameters, but the V98.1 Edge Function was still calling the old 5-parameter RPC signature.
8) create-infinity-payment now creates/reuses the pending Advanced Course enrollment server-side, so Local Bank Transfer no longer needs enrollment questions before redirect.
